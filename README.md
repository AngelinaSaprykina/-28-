# -28-
Разработка эмулятор для языка оболочки ОС
Эмулятор командной строки UNIX-подобной операционной
системы на языке Python.

## Этап 1. REPL

Реализованы:

- консольный интерфейс;
- приглашение username@hostname:~$;
- получение username и hostname из реальной ОС;
- раскрытие переменных окружения;
- простой парсер;
- команда-заглушка ls;
- команда-заглушка cd;
- команда exit;
- обработка неизвестных команд.

## Запуск

python src/emulator.py

Или:

run.bat

## Тестирование

python -m pytest
